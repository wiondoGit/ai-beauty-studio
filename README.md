## 📋 项目简介

AI Beauty Studio 是一个面向美业从业者（理发店、美容院、美甲店）的AI工具集与自动化推广方案平台。整合15+款核心AI工具，提供发型推荐、妆容定制、美甲款式生成的一站式解决方案。

## ✨ 功能特性

### 🛠️ AI工具收藏中心
- **15+款精选AI工具**，覆盖图像、视频、数字人、音乐等场景
- **智能分类筛选**：AI平台、图像生成、视频生成、数字人、音频生成、实用工具
- **一键快速访问**，提高工作效率

### 💇‍♀️ 三大美业应用场景

#### 1. AI发型推荐系统（理发店）
- 拍摄客户正面照片 → AI智能分析 → 生成9款发型方案 → 客户选择确认
- **核心价值**：自动生成，无需发型师一对一沟通，提升3倍接待效率

#### 2. AI妆容定制系统（美容院）
- 面部特征采集 → 风格偏好选择 → 生成妆容方案 → 产品推荐匹配
- **核心价值**：标准化妆容咨询流程，降低沟通成本，提升成单率

#### 3. AI美甲款式推荐（美甲店）
- 手部信息采集 → 季节/场合匹配 → 生成款式方案 → 一键替换展示
- **核心价值**：模板化生成，自动替换，实现小范围自动化推广

### 🔄 自动化推广工作流

```
客户进店 → AI分析 → 生成方案 → 客户选择 → 保存推送
```

## 🚀 快速开始

### 本地使用
1. 下载本项目文件
2. 直接双击 `index.html` 在浏览器中打开
3. 无需安装任何依赖，即开即用

### 部署到服务器
1. 将项目文件上传到任意静态网站托管服务
2. 推荐使用 GitHub Pages、Vercel、Netlify 等免费服务
